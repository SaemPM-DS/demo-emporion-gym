# Gimnasio Emporion — Demo web

Demo de landing page para **Gimnasio Emporion** (Calz. Melchor Ocampo 26, Centro, Tula de Allende, Hgo.).

Incluye: horario con estado "Abierto / Cerrado" en tiempo real, servicios, planes, galería de instalaciones, mapa de Google Maps y botón flotante de WhatsApp.

## Ver la demo

Abre `index.html` en el navegador o visita la versión publicada en GitHub Pages.

## Configuración

- **WhatsApp:** cambia `WHATSAPP_NUMBER` al final de `index.html` (formato `52` + 10 dígitos).
- **Horario:** edita el arreglo `SCHEDULE` en `index.html`.
- **Precios y reseñas:** son de ejemplo; edítalos directamente en `index.html`.
